## Overview

BloodFinder connects blood donors with people who need blood urgently.

## Key Features

- Search donors in real time
- Post and respond to emergency blood requests
- Clean, mobile-friendly interface built with DaisyUI

## Tech & Decisions

Built with React, Tailwind CSS and DaisyUI for fast UI development, with React Router handling navigation between pages.
