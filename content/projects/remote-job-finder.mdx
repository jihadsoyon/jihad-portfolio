## Overview

A full-featured platform for finding remote jobs, with authentication, payments and analytics.

## Key Features

- Search and browse remote job listings
- Secure sign-in with Better Auth
- Payments handled with Stripe.js
- Charts and insights built with Recharts

## Tech & Decisions

Next.js and React for the frontend, with Node.js, Express.js and MongoDB on the backend. Framer Motion adds smooth transitions throughout.
