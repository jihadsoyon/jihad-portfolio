## Overview

AI StudyMate is an all-in-one learning companion that helps students study smarter with AI-assisted help.

## Key Features

- AI-powered study assistance using the Cohere API
- Organised learning flow with React Router
- Progress saved locally with localStorage

## Tech & Decisions

Built with React and Tailwind CSS for a fast, responsive interface, with Cohere AI for the intelligent responses.
